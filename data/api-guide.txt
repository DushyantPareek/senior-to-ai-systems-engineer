REST APIs allow software applications to communicate over HTTP using requests and responses.
Clients send HTTP requests to API endpoints and servers process those requests and return HTTP responses.

HTTP methods describe the type of operation being requested.
GET is commonly used to retrieve data, POST to create data, PUT to update data, and DELETE to remove data.

API authentication verifies the identity of a client before allowing access to protected resources.
APIs may use mechanisms such as API keys or access tokens for authentication.

HTTP status codes communicate the result of a request
For example, successful requests may return a 200 status code, while client errors may return a 400-series status code.
